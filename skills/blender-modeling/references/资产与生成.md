# 资产获取与生成：blender_py 脚本模板

> 适用：v3.3.1。**目前没有资产类 op**——搜索与状态走 `blender_inspect`，下载/导入/提交生成必须用 `blender_py` 写脚本（或 `blender_run(kind="headless")` 跑长活）。
> 为什么这样分工：addon 里保留了 PolyHaven / Sketchfab / Poly Pizza / Hyper3D / Hunyuan3D 的集成客户端，但**下载与导入命令没有注册到模型面**（避免未经校验的写操作直接进场景）。所以模型要自己写这段，写完必须复检。

## 0. 先确认开关（不做这步，搜索命令会回 command_disabled）

```
blender_inspect(command="get_polyhaven_status")
blender_inspect(command="get_sketchfab_status")
blender_inspect(command="get_polypizza_status")
blender_inspect(command="get_hyper3d_status")
blender_inspect(command="get_hunyuan3d_status")
```

开关是 **scene 属性**（`bpy.context.scene.dshbb_use_*`），在 Blender 的 N 面板「DSH」页勾选；换 .blend 后可能回到关闭状态，**每个会话第一次用资产前都要确认**。

## 1. PolyHaven（免 key）

```
blender_inspect(command="search_polyhaven_assets",
                args={asset_type:"models", query:"chair", limit:8})
```

拿到 `id`（slug）后，下载与导入：

```python
# blender_py：PolyHaven 资产 → 下载 → 导入 → 命名 → 归集合
import json, os, zipfile, tempfile, urllib.request, bpy

ASSET_ID   = "modern_arm_chair_01"   # 换成搜索结果里的 id
ASSET_TYPE = "models"                # models / textures / hdris
RESOLUTION = "1k"
FMT        = "gltf"

api = f"https://api.polyhaven.com/files/{ASSET_ID}"
with urllib.request.urlopen(api, timeout=30) as r:
    files = json.load(r)
url = files[RESOLUTION][FMT]["gltf"]["url"]

tmp = tempfile.mkdtemp(prefix="ph_")
zpath = os.path.join(tmp, ASSET_ID + ".zip")
urllib.request.urlretrieve(url, zpath)
with zipfile.ZipFile(zpath) as z:
    z.extractall(tmp)

before = set(bpy.data.objects.keys())
imported = []
for root, _dirs, names in os.walk(tmp):
    for n in names:
        if n.endswith((".gltf", ".glb")):
            bpy.ops.import_scene.gltf(filepath=os.path.join(root, n))
            imported += [o.name for o in bpy.context.selected_objects]
print("imported:", imported)
print("new objects:", sorted(set(bpy.data.objects.keys()) - before))
```

导入后**必须**补三步（否则场景里会留下无主对象）：

1. 统一命名与归集合：`bpy.data.objects[name].name = "PH_" + ASSET_ID`，再 `bpy.data.collections.new("assets")` 收进去；
2. 单位与尺度：PolyHaven 资产按米建模，若 `scene.unit_settings.scale_length != 1` 先换算，并在回执里写清 mm；
3. 体检：`blender_op(op="audit_mesh", args={objects:[...]})` —— 非流形/碎面不通过就不要往下做。

## 2. Sketchfab（需要 key）

key 存在 addon 偏好或环境变量 `DSHBB_SKETCHFAB_API_KEY`。

```
blender_inspect(command="search_sketchfab_models", args={query:"vintage camera", count:10, downloadable:true})
```

下载需要走两次请求（先换下载地址，再取 zip）：

```python
# blender_py：Sketchfab uid → 下载地址 → zip → glb → 导入
import os, json, zipfile, tempfile, requests, bpy

UID = "0123456789abcdef"           # 搜索结果里的 uid
prefs = bpy.context.preferences.addons["dsh_blender_bridge"].preferences
key = prefs.sketchfab_api_key or os.environ.get("DSHBB_SKETCHFAB_API_KEY", "")
assert key, "没有 Sketchfab key：偏好里填，或设 DSHBB_SKETCHFAB_API_KEY"

r = requests.get(f"https://api.sketchfab.com/v3/models/{UID}/download",
                 headers={"Authorization": "Token " + key}, timeout=30)
r.raise_for_status()
url = r.json()["gltf"]["url"]

tmp = tempfile.mkdtemp(prefix="sf_")
zpath = os.path.join(tmp, "model.zip")
with requests.get(url, stream=True, timeout=60) as resp:
    resp.raise_for_status()
    with open(zpath, "wb") as fh:
        for chunk in resp.iter_content(1 << 20):
            fh.write(chunk)
with zipfile.ZipFile(zpath) as z:
    z.extractall(tmp)
for root, _d, names in os.walk(tmp):
    for n in names:
        if n.endswith((".gltf", ".glb")):
            bpy.ops.import_scene.gltf(filepath=os.path.join(root, n))
```

**不要把 key 写进脚本或回执**：脚本里只从偏好/环境变量读，print 时不要打印 key。

## 3. Poly Pizza（免 key，单 glb）

```
blender_inspect(command="search_polypizza_models", args={query:"tree", limit:10})
```

搜索结果里带 `Download` 直链，直接下 glb：

```python
import tempfile, os, requests, bpy

URL = "https://…/model.glb"        # 用搜索回执里的 Download 字段
tmp = tempfile.mkdtemp(prefix="pp_")
path = os.path.join(tmp, "model.glb")
with requests.get(URL, stream=True, timeout=60) as r:
    r.raise_for_status()
    open(path, "wb").write(r.content)
bpy.ops.import_scene.gltf(filepath=path)
```

## 4. 生成资产（Hyper3D Rodin / Hunyuan3D）

生成是**长任务**：提交后不要阻塞在 GUI 里轮询，用 `blender_run(kind="headless")` 提交脚本，或提交后先做别的活，隔一段时间查一次。

- 轮询只读命令：`blender_inspect(command="poll_rodin_job_status")` / `command="poll_hunyuan_job_status"`；
- 生成结果的导入：拿到下载地址后用第 1/3 节的下载 + `bpy.ops.import_scene.gltf` 模板；
- 生成网格通常**面数爆炸、没有 UV、没有正确尺度**：导入后先 `fix_decimate` → `uv_smart_project` → `geo_* / audit_mesh`，不要直接进交付。

## 5. 硬规则（踩过就不要再踩）

1. **不要**在 `blender_py` 里写 `wm.read_factory_settings` / `wm.read_homefile`：会连 addon 一起卸载，GUI 通道直接死（工具会拦，返回 `factory_reset_blocked`）。
2. 下载目录用 `tempfile.mkdtemp()`，不要写到工程交付目录；需要留档时显式复制到 workspace 并回 md5。
3. 每个导入脚本结尾都要 `print` 出「新增对象名 / 面数 / bbox」，然后用 `blender_op(op="audit_mesh")` 复核；**没有复检就不算导入成功**。
4. 一次只导一个资产：批量循环容易在超时后重跑而重复导入（见 SKILL §0.2 的超时口径）。
