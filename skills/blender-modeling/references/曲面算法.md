# 曲面算法参考（surface_*）

纯 bpy + numpy 的参数化曲面：spec → 网格 → 质检 → GLB。不依赖 OCCT / geomdl / trimesh，随插件发布，GUI 与无头都能跑。

## 1. 何时用

- 截面放样：瓶身、罩壳、机身段、车顶过渡 → surface_loft
- 沿路径扫掠：管、梁、裙边、线缆走向 → surface_sweep
- 四边补片：A 面过渡、局部曲面 → surface_patch
- 已有 spec 落网格 → surface_tessellate
- 网格体检（连续性/曲率/自交/厚度） → surface_validate
- 导出 GLB 给外部查看/交付 → surface_export

基本体/分面硬表面用 bmesh/geo+Bevel；有机用 sculpt_*；需要 G2/CAD 偏置不要用本族。

## 2. op 与关键参数

| op | 关键参数 | 说明 |
|---|---|---|
| surface_loft | sections=[{z_mm, points_mm:[[x,y]...]}]、degree(1..7)、continuity(G0/G1/G2)、closed、tessellation{u,v} | 插值型 B-spline 过截面；z 沿 v 线性 |
| surface_sweep | profile_mm、rail_mm、orientation(auto/up_z/up_y/fixed)、twist_deg、scale | 平行传输标架 + 累积 twist + 逐点 scale |
| surface_patch | control_grid（规则网格）、degree_u/degree_v | 张量积 clamped B-spline 面片 |
| surface_tessellate | spec_or_object、quality(draft/normal/fine) | spec→网格；对象→烘焙求值网格 |
| surface_validate | spec_or_object + continuity/curvature/self_intersection/thickness 开关 | 返回 verdict/metrics/checks/defects/next |
| surface_export | spec_or_object、out_dir、name | 导 GLB；返回 path/bytes/tris |
| surface_fit | points=[[x,y,z]...]、axis(x/y/z)、sections、ring、degree、tolerance_mm | M3 近似：切环 → 极角排序 → 等弧长重采样 → loft；回执 residual_mm + verdict |
| surface_offset | spec_or_object、distance_mm（正=向外）、max_tris | M5 近似：顶点法线偏置；回执 method=vertex_normal + verdict + self_intersections |
| surface_blend | a、b（对象名=开放面片边界环，或点列）、rows、samples、closed | M5 近似：smoothstep 过渡面；method=smoothstep_bridge，不保证相切 |
| surface_selftest / surface_help | 无参 | 真机自检 / 参数速查 |

SurfaceSpec 字段：`kind`(loft/sweep/patch)、`units:"mm"`、`degree`(1..7)、`continuity`(G0/G1/G2)、`closed`、`constraints{min_thickness_mm, max_curvature_1_per_mm, g1_tol_deg, g2_tol_ratio}`（可选，validate 用）、`tessellation{u,v}`（或 `quality: draft|normal|fine`）。

## 3. 单位与可复现

- 所有长度 mm；内部按 scene.unit_settings.scale_length 折算；
- 同 spec（含 tessellation）⇒ spec_hash 相同、顶点一致（无随机数、不用 bpy.ops）；
- 对象名不影响 spec_hash。

## 4. verdict 三态

- pass：声明连续性达标、无自交、闭合壳厚度达标、网格质量正常；
- fail：确认缺陷（自交/G1 不连续/超曲率/翻转法线/退化面/厚度不足）；
- degraded：检查没跑成（超 max_tris、厚度量不到）—— **degraded 不等于通过**；
- 开放曲面厚度 n/a，不是 fail；defects[] 逐条给 check/severity/msg，checks 是各项原始数字，next 给下一步建议。

## 5. 最小链路

    surface_loft(sections=[...], degree=2, closed=true, tessellation={u:24,v:8}, name="Cowl")
      → surface_tessellate(spec_or_object=<spec>)        # 拿 object 名
      → surface_validate(spec_or_object=<object>)        # 读 verdict
      → surface_export(spec_or_object=<object>, out_dir="D:/out", name="Cowl")

## 6. fit / offset / blend 怎么用（近似，不是 BRep）

    # 点云 → 切环拟合（残差是原始点到重采样环的距离）
    surface_fit(points=[[x,y,z],...], axis="z", sections=8, ring=24, tolerance_mm=0.5)
      → 回执 residual_mm{rmse_mm,max_mm,per_section} + verdict（超 tolerance ⇒ degraded）

    # 沿顶点法线等距偏置（正=向外）
    surface_offset(spec_or_object=<spec|object>, distance_mm=2.0)
      → 回执 verdict(pass|degraded|fail) + self_intersections；尖角/凹处可能自交

    # 两条边界环之间的过渡面（对象名取开放面片的最长边界环）
    surface_blend(a=<object|[[x,y,z],...]>, b=<...>, rows=16, samples=24)
      → 回执 method=smoothstep_bridge；不保证相切/圆角

三者都标 `quality:"approximate"`：**fit 不是 BRep/点云求解器，offset 不是稳健 offset，blend 不是相切圆角**。
稳健 BRep 操作仍需 OCCT 后端；验收一律读回执的 `verdict` / `residual_mm` / `self_intersections`，不要只看 `ok:true`。

## 7. 限制（如实）

- 截面之间是 B-spline 插值（过点），但 z 沿 v 线性；不是 NURBS 曲面；
- 连续性只在有缝方向可查（loft section 缝 / sweep 闭合接缝）；单张 patch 为 n/a；
- 曲率/厚度是离散近似，对三角化密度敏感，**不能作为制造认证**；
- fit 每截面独立拟合，跨截面只做 loft 插值；点云稀疏/跨特征切环时残差会大（看 per_section）；
- offset 用顶点法线，尖角/凹处可能自交（verdict=fail）；blend 是点对点 smoothstep，不保证相切；
- 大网格先降密度，自交检查超限会 degraded（degraded ≠ 通过）。

## 8. 配合

- 比例：img_digest → probe/measure → calib 先量 mm；
- 轮廓：shapesolve_solve 反推尺寸后再写 spec；
- 项目验收：surface_validate 是单元体检，最终走 gate_*（三态）；
- 交付：surface_export 出 GLB，装配/交付走 asm_export / deliver_export；
- 视觉：qc_render_views / visualreport_report 同机位对比；
- 后端：真 BRep 的接入计划（暂缓、未排期）见 [docs/OCCT后端-接入计划.md](../../../docs/OCCT后端-接入计划.md)。
