## 1. 前提更正（先看这三条）

1. **catalog 数量**：你测到的 **35 family / 261 op 与本仓 HEAD 完全一致**，不是装错，也不是旧包。当前工作树因未提交的 `asset` 族显示 36/264；评估与排期仍以 HEAD 的 35/261 为基线。
2. **端口**：3.1+ 唯一入站端口是 **Gateway `127.0.0.1:39877`**；addon 主动拨入，**不监听**；`9879` 是热无头 worker；`9877` 是 3.0.x 旧后端（仅显式配置时生效）；`9878` 是 Windows 启动代理。用 9877 判断“没起”会把正常状态误判成故障。
3. **P9 不是“依赖 FFMPEG 就死”**：HEAD 的 `blockout_turntable` 已经 `try/except` 回退 PNG 序列，并写 `degraded/ok:false/warnings`（`runtime/py/geometry/blockout_impl/present.py`）。真正缺的是 **enum 预检字段**（`ffmpeg_available` / `fallback`）与 **`ffmpeg_exe` 外挂编码**。

> 另注：CI 只跑 Blender **4.2.10**，5.3 尚未验证（`docs/zh/CONTRIBUTING.md`）；P10 属于未验证版本上的 API 漂移，M0 先修已确认的 blockout 路径，M1 再补 5.3 CI。
